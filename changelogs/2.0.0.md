# 2.0.0 Overview

This major version bump changes modloaders from FORGE -> NEOFORGE with minecraft version 1.21.1. It is likely not compatible with previous 1.x.x versions of this modpack and has a reduced modcount. Future 2.x.x releases will add/remove mods as the curation process takes place. This Release is focused on a core modlist that functions together with the new modloader.
